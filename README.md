## Trellis

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/Revazi1st/Trellis/main/eng/readme/title-dark.svg">
  <img alt="Trellis, a best-practices .NET 10 solution template, beside a terminal with its two install commands" src="https://raw.githubusercontent.com/Revazi1st/Trellis/main/eng/readme/title-light.svg" width="100%">

A `dotnet new` template for .NET 10 that generates a rich-DDD, Clean Architecture solution: vertical-slice features, CQRS without a mediator, `Result`s instead of exceptions, PostgreSQL, Identity with JWT, Aspire orchestration and an optional Blazor UI, in a repository written for AI agents as carefully as for people.

```bash
dotnet new install Trellis.Templates
dotnet new trellis -n Your.Project
```
